4kiscan

Crypto transaction evaluator

4kiscan uses public network data and what you declare. It cannot access exchange or bridge internal systems and is not legal or financial advice.

Network connection

To check what really happened to a transaction, 4kiscan queries the network through Alchemy. You need a free Alchemy API key with Ethereum, Polygon, Optimism, Arbitrum and Base enabled.

The key is sent only to Alchemy from your browser. It does not pass through any other server. If unchecked, it will be forgotten when this tab closes.

You can also use the evaluator without a key: the conclusion will rely only on what you declare.
